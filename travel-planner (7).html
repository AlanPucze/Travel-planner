Карта

Точки берутся автоматически из поля «Ссылка на карты» у каждого места (вкладка «Места») — просто вставьте туда ссылку на Google/Naver/Яндекс Карты, и место появится здесь само. Выберите день внизу, чтобы увидеть только его точки и маршрут между ними — удобно проверить, логично ли скомбинированы места по дням.

🇰🇷 Хотите карту именно Naver вместо OpenStreetMap? (точнее для Кореи, но нужна бесплатная регистрация)

Карта выше — OpenStreetMap, она открывается сразу и без настроек. Naver Maps детальнее знает корейские адреса и небольшие заведения, но Naver не даёт встраивать карту без бесплатной регистрации приложения на ваш домен — таковы их правила, обойти нельзя.

  1. Зайдите на console.ncloud.com и зарегистрируйтесь (нужен номер телефона)
  2. Откройте Services → AI·NAVER API → Maps, нажмите «Application 등록/Register»
  3. Выберите сервис Web Dynamic Map, впишите адрес, с которого откроете этот файл (например, ваш адрес на GitHub Pages — если открываете локально, впишите http://localhost или file:// смотря как открываете)
  4. Скопируйте выданный Client ID и вставьте его в поле ниже
